## Що я забрав із портфеля neRoma32

У портфелі neRoma32 використано формат Given/When/Then, який явно визначає передумови, дію та очікуваний результат перевірки. Цю знахідку описано в розділі 4 моєї [рецензії](review.md). Для моєї S-11 підготував три сценарії без зміни її обсягу й оцінки:

| Given | When | Then |
| --- | --- | --- |
| Користувач має роль адміністратора, ID бази ще немає в переліку | Додає базу з цим ID | У переліку є один новий запис |
| База є в переліку, але ще не опублікована | Студент відкриває перелік; після публікації повторює перегляд | До публікації бази не видно, після публікації видно |
| У переліку вже є база з указаним ID | Адміністратор повторює додавання того самого ID | Другий запис не створюється |

Це підготовка перевірки. S-11 лишається Ready поза обсягом спринта 2, без дати завершення і без зарахованих SP.
