## 4. Знахідка

У [S-11, backlog.csv:10](https://github.com/neRoma32/pm-2026-kn41-androshchuk/blob/500215dea650118c00d88afabe7f2442541a2235/lr06_backlog/backlog.csv#L10) умови додавання запису та відхилення дубліката викладені через Given/When/Then. Для цих перевірок передумова й момент перевірки явніші, ніж у моїх коротких критеріях каталогу.

Переношу цей спосіб запису в підготовчі сценарії своєї S-11: додавання бази адміністратором, приховування неопублікованої бази від студента та відхилення повторного ID. Сценарії записані в README реакції; вони готують майбутню перевірку, не означають завершення S-11.
